# Initial Rust Port: v0.1.0

This page isolates the initial proof from later maintenance-loop claims.

## Claim

Python Millrace `v0.16.1` autonomously produced the first Rust
`millrace-ai v0.1.0` parity implementation through a large staged implementation
campaign.

## What This Proves

- Python Millrace accepted eight seeded Rust-port parity ideas.
- It decomposed them into specs, tasks, closure targets, and remediation work.
- It executed a long Codex-backed campaign through Millrace stages.
- It routed build/check/update loops, fixes, double-checks, Arbiter
  remediation, and learning side work.
- It produced the Rust `millrace-ai v0.1.0` crate state.

## What This Does Not Prove

- It does not prove the Rust crate rebuilt itself.
- It does not prove autonomous publishing, tagging, or repository
  administration.
- It does not prove universal arbitrary software development.
- It does not contain every raw private artifact in the public repo.
